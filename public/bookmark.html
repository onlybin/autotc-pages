生成台账书签

一次生成，之后在手机上随手点一下就能完成上报

怎么用（就三步）

  1. 点上面的「复制书签代码」。
  2. 在浏览器里随便存一个书签，把它的「网址」换成刚复制的东西。
  3. 以后不管在哪个页面，点这个书签就行 —— 没登录它会自己跳到 MXIPOS，登录好再点一次，数据就上去了。

书签在「新标签页」上点也没问题，它会自动带你去 MXIPOS，不用先自己找页面。

安卓 / Chrome 具体操作

  1. 随便打开一个网页 → 右上角菜单 → 星标（加书签）→ 保存。
  2. 菜单 → 书签 → 长按刚存的那个 → 编辑 → 把「网址」整段删掉，粘贴上面复制的代码 → 保存。
  3. 点它即可。

iPhone / Safari 具体操作

  1. 点分享按钮 → 添加书签 → 存到「个人收藏」。
  2. 打开「书签」→ 编辑 → 点刚存的那个 → 把地址改为上面复制的代码 → 完成。
  3. 之后在书签里点它即可。

部分浏览器会过滤 javascript: 前缀，若点击完全没反应，改用下方兜底方式。

兜底：粘贴提交

书签失效时，直接打开 会话上报页，粘贴会话内容与口令提交即可。书签若报「网络错误」，会自动把会话复制到剪贴板，直接粘贴过去。
