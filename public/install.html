一次性设置

装好之后，登录 MXIPOS 就自动上报，什么都不用点
要装 两样东西，缺一不可：
① 一个能装插件的浏览器（Firefox）
② 一个叫 Tampermonkey 的插件 —— 真正干活的是它
只装浏览器不装插件，等于买了手机没装卡，什么都不会发生。

四步装完

1
装 Firefox 浏览器
应用商店搜 Firefox，免费。装完先打开一次。
2
在 Firefox 里装 Tampermonkey 插件
Firefox 右上角 ⋮ 菜单 → 附加组件 → 搜索 Tampermonkey → 点「添加到 Firefox」→ 允许。
装好后地址栏右边会多出一个 Tampermonkey 图标，说明插件到位了。
3
安装台账脚本
回到这个页面，点下面绿色按钮 → Tampermonkey 会弹出一个安装页 → 点「安装」。
4
用 Firefox 登录 MXIPOS
登录成功那一刻，右下角会弹「台账已更新」。以后每天只要打开 Firefox 登录就行，不用点任何按钮。
安装台账脚本
第 3 步才点这个按钮，前两步没做完点了也没反应

怎么确认装好了

  • Firefox 菜单里能看到「附加组件」，里面列着 Tampermonkey → 插件好了。
  • 点 Tampermonkey 图标 → 管理面板里能看到「MXIPOS 台账自动上报」→ 脚本好了。
  • 登录 MXIPOS 后右下角弹绿字 → 全部好了。

不想装两样东西？

用现在手机上的浏览器（Chrome 也行）加一个书签，每次在 MXIPOS 页面上点一下。功能完全一样，只多一次点击。

去打书签页
进入后输入你自己的上报口令，口令由店主单独发放，不写在网页上

为什么非要插件：手机版 Chrome 不允许装任何插件，所以要在 Chrome 里做"零点击"在技术上不成立。Firefox 是目前手机上唯一正规支持插件的浏览器。
